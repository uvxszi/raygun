# M46.9.1 — Sources that work

**Relevant docs:** M17 (Nuclear plugins), M32 (Shosetsu runtime), M46.2 (repository icons), M46.7 (installs), M46.8 (the converter's provider scan).

## Goal
- **Shosetsu scripts** that work in Shosetsu should work in Raygun. A survey (an ignored test) installs every script of the official repository and runs listing, novel, chapters and a passage. Each failure is put in one of two groups:
  - a gap in Raygun: fix it in the runtime;
  - the site's or the script's: fix the script for Paraline if the site is legitimate, or leave it.
- **Nuclear plugins** that run in Nuclear should run in Raygun, and plugins already installed should get the fixes without reinstalling by hand.
- **Paraline Raygun** (`uvxszi/paraline-raygun`), a separate public repository:
  - fixed copies of sources for legitimate sites;
  - installable in Raygun, and in Shosetsu for its novel sources;
  - suggested in Raygun's repository list.
- **Out of scope:**
  - sites that refuse Raygun with 403s or bot checks: not worked around;
  - scrapers of unlicensed copies: not shipped or fixed.

## Design
- **Shosetsu runtime (`raygun-ext-host::shosetsu`):**
  - The index's "md5" (SHA-256) no longer refuses a script. Shosetsu keeps it only to spot updates, and its repository changes scripts without updating it. A mismatched script must still start with a script's metadata line, so an error page never installs. Libraries stay checked.
  - Response bodies up to 16 MiB.
  - Jsoup's `appendElement`/`prependElement` (return the new element) and `appendText`/`prependText` (escaped).
- **TLS (`raygun-net`):** desktop verifies with the operating system's verifier (`rustls-platform-verifier`), which fetches missing intermediate certificates as browsers do. Android keeps the bundled roots.
- **Nuclear (`raygun-ext-host`, `packages/nuclear-compat`):**
  - Converted plugins reach any public host as well as the hosts found in their code. Nuclear runs plugins without a host list, and their code builds addresses the converter can't see.
  - They may register any kind Raygun runs for Nuclear (`music.metadata`, `music.stream`, `lyrics`) without declaring it.
  - The shim:
    - gives an inert `document`/`window` to plugins that draw in a page;
    - turns unknown methods of the API domains into logged no-ops;
    - accepts `Settings.registerWidget`.
  - Conversions are stamped with `CONVERTER_VERSION` (2), and `CompatReport::converter` carries it (1 when missing). The catalogue offers a Nuclear plugin converted by an older converter as an update at the same version, shown as "converted again with fixes".
- **Paraline Raygun:**
  - `shosetsu/`: a Shosetsu-format repository (`index.json`, `src/<lang>/<Name>.lua`, `lib/`), built by `tools/build_index.py`.
  - Scripts keep their ids, so a fixed copy is an update over the official one.
  - GPL-3.0, as the scripts it adapts.

## Done-check
- **Rust:**
  - scripts with a stale hash install, error pages don't, and libraries stay checked;
  - the DOM's new methods;
  - Nuclear conversions get any public host plus their own and never local ones;
  - undeclared Nuclear kinds load and other undeclared kinds don't;
  - the converter's stamp agrees with the Rust constant;
  - catalogue states for stale conversions.
- **Vitest:** the catalogue row for a same-version conversion update.
- **Converter tests:** plugins that draw in a page or call newer APIs.
- **Survey:** the official repository from a checkout, and Paraline's scripts.
- 🖥️ **On Windows:** the suggested Paraline repository, a Paraline novel from listing to chapter text, and Nuclear plugins offered again.

## Decisions
- **What counts as a gap in Raygun:** a script that fails the same way in Shosetsu is the site's or the script's problem. Shosetsu's `map` errors on nil just as Raygun's does, so Ranobehub, Renovels and Ruvers fail because their APIs changed (Ranobehub answers `{"books":[],"entities":[]}`).
- **Hashes:** checking the metadata line, rather than refusing, matches Shosetsu and still stops HTML error pages and rate-limit replies.
- **No User-Agent changes:** Syosetsu serves phone markup to phone browsers. The fix reads the desktop layout in the script; Raygun doesn't pretend to be a phone.
- **Left alone:**
  - 403s and bot checks (Royal Road, Scribble Hub, Foxaholic, Rulate, Honeyfeed, Novelhall, FanFiction.Net, FiMFiction, SpaceBattles, AltHistory, Central Novel, Inkitt's pages, Webnovel's challenge page, NOVA's CAPTCHA);
  - sites that are gone (Jaomix, RanobeRF, LightNovelBastion, NovelNB, Creative Novels' 522, Knoxt's 500, BLNovels' 404) or whose TLS is broken for every client (NeoSekai: Windows' own TLS fails too);
  - fan-translation and aggregator sites whose markup changed (Sky MTL, Rain of Snow, Travis Translations, LightNovelPlus, Zetro, NovelTL, Shanghai Fantasy);
  - Kemono, which reposts paywalled work: its 16 MB creator list exceeds the Lua memory cap.
- **Zelluloza** (legitimate, authors' own books) moved to new markup throughout. It is a Paraline candidate for a later pass.
- **Nuclear conversions keep local hosts out:** only hosts named in the plugin's code are allowed besides public ones. A Subsonic server on the local network therefore needs Raygun's own support, not the plugin's.
- **Re-offering conversions:** comparing a converter version, not the bundle bytes, keeps the check cheap and lets a later converter change decide what's worth reinstalling.

- **Failed conversions keep their report:** a conversion that fails to load still carries its compatibility report, so a newer converter is offered for it. That's how mini-player and Subsonic, which failed under converter 1, come back as updates.

## Verification
- **Checks:**
  - Rust:
    - stale hashes install, error pages don't, libraries stay checked;
    - `appendElement`/`appendText` escaping;
    - Nuclear: any public host plus found hosts, never local ones;
    - undeclared Nuclear kinds load, other kinds don't;
    - a failed conversion keeps its converter version;
    - the converter stamp equals the Rust constant;
    - catalogue states for stale conversions.
  - Vitest (347): the "converted again with fixes" row.
  - Converter tests (15).
  - Clippy and the workspace tests clean.
- **Survey:**
  - The official repository, from the 30 October checkout, works for 24 of 60 scripts (16 before). The rest fail for the reasons in Decisions.
  - Paraline's Syosetsu and Wattpad pass listing → novel → chapters → text.
  - The pushed repository serves files whose hashes match its index.
- 🖥️ **On Windows (release build):**
  - Browse → Extensions → Browse listed the installed Nuclear plugins as "converted again with fixes".
  - Update all reinstalled twelve; the log shows them loading.
  - Subsonic and mini-player weren't offered (they had failed to load). That led to the fix above; checked again with M46.9's build.
  - GitLab was rate-limiting the Shosetsu index at the time (HTTP 429), after the survey runs.
