# M46.28 — Paraline Community (local) and local repositories

**Asked by the user (2026-11-02):** "we will have Paraline as the open source that it gets suggested. but also just make a separate repo and make it only on my local pc, and this one we will have as much sources and plugins and stuff as possible, called it paraline-community-raygun but this won't be pushed online, we need to test a lot of working sources and fix issues in the future with it, while testing how this repo installed into raygun. … put both of the paraline repos as folders in my projects folder".

## Goal
- **Paraline Raygun** (`C:\Users\fn\Projects\paraline-raygun`, pushed to `uvxszi/paraline-raygun`) stays the repository Raygun suggests.
- **Paraline Community Raygun** (`C:\Users\fn\Projects\paraline-community-raygun`): a git repository with no remote, never pushed. It's a test bed holding every source and add-on Raygun can run that works:
  - `shosetsu/`: Shosetsu scripts for legitimate sites (original-fiction platforms, official publishers' free sites, public-domain libraries), with Paraline's fixes and the libraries. `tools/build_index.py` writes the index.
  - `raygun/`: a Raygun-format repository (`index.json` and `packages/`, built with `raygun-ext pack`): Raygun's first-party extensions, and new community sources as they're written. The first is **Openverse audio**: openly licensed songs from Openverse's API, with search and streams.
  - `nuclear/plugins.json`: a Nuclear registry listing the plugins that convert and load.
  - `stremio/addons.md`: addon addresses of legitimate catalogues (Cinemeta, Public Domain Movies, OpenSubtitles…) to add by hand.
  - `SURVEY.md`: what each source did in the last survey, so fixes can be planned.
  - `tools/serve.py`: serves the folder on `127.0.0.1:8765`. The emulator reaches it through `adb reverse tcp:8765 tcp:8765`.
- **Raygun reads local repositories:**
  - On desktop a repository can be a local index: a `file:///…/index.json` address or a plain path. Packages and scripts are then read from beside it.
  - `http://127.0.0.1` and `http://localhost` addresses work everywhere (the emulator through `adb reverse`), so the community repo installs as it would from the web.

## Decisions
- **Same rule as Paraline:** legitimate sites only, even locally. No scrapers of unlicensed copies, nothing that gets around bot checks.
- **File addresses are desktop-only:** on Android the app can't see the PC's folders, and `adb reverse` with the server is the same path a web repository takes.
- **Plain `http` only for loopback:** remote repositories still need `https`.

## Verification
- **Tests:** a local path and a `file:` address are repositories on desktop, with packages beside the index; `file:` stays refused on Android; plain `http` stays loopback-only.
- **The repository** (`C:\Users\fn\Projects\paraline-community-raygun`, git with no remote; three local commits):
  - 17 Shosetsu scripts for legitimate sites, with 11 libraries and the index;
  - a Raygun-format repository of 14 extensions: Raygun's 13 and Openverse audio;
  - Nuclear's registry (23 plugins, the soundtrack-rip one left out);
  - Stremio addon addresses, `tools/serve.py`, `tools/build_index.py`, and the README.
- **Survey:** 6 of 17 novel sources work end to end (Parahumans, Questionable Questing, Sufficient Velocity, Wattpad and Syosetsu from Paraline, Author.Today). The rest are in `SURVEY.md`: bot checks (left alone), a moved page (Inkitt), a page over Raygun's 16 MiB cap (Webnovel), new markup (Zelluloza) and a site that's down.
- **Openverse:** the audio API answered a search with titles, creators, durations and file addresses (Freesound, Jamendo).
