# M46.17 — Calm source failures, a test pack, and video sources that learn

## Goal
- **Calm failures:** `shell/SourceIssue` replaces red errors wherever content comes from a source.
  - It reads "Issue with <source>" (or "Issue with source") with a reassuring line, and "Try again" where the page can ask again.
  - "More info" shows the full error, selectable, with "Copy details".
  - It keeps `role="alert"` and the full text in the page, so assistive tech and tests still read it.
  - Settings and form errors stay as they are.
- **A test pack** (`repo-test/`, built by `tools/build_test_sources.py`; never shipped or pre-added):
  - Extensions that fail on purpose: one that always throws (music and manga), one that never answers, one that returns garbage (missing fields, wrong types, huge text, bad links), one that hands out dead streams, and one that crashes while loading.
  - A static Stremio addon of legal films (Blender's Sintel, Tears of Steel, Big Buck Bunny, Elephants Dream; Internet Archive copies; HLS and DASH test servers). Dead links come first, plus one film whose links are all dead, and live news channels from the broadcasters' own hosts (Al Jazeera's dead host first).
  - Settings → Data → **Developer: test sources** adds every suggested repository, the test repository and the test addons. The addons are Raygun's own, Cinemeta, OpenSubtitles v3, Public Domain Movies (torrents: unsupported, shown as such), WatchHub (outside links), YouTube channels, Pluto TV and Radios.
  - "Install everything from repositories" queues every listed extension.
- **Video sources that learn:**
  - Play sessions already fall back to the next link.
  - Servers and addons that failed since they were last tried now go to the end of the list for three days (`video.sourceHealth`).
  - The source list marks them "didn't work lately" on both players; the mark clears as soon as one of their links plays.
- **One silent source can't stall the rest:** searches, stream lookups and artist/album lookups give up on a source after 12 s (`call_interactive`); background work keeps the 30 s limit.

## Decisions
- `SourceIssue` was swapped in by a script for the `<p role="alert">` pattern in 39 source-facing files (53 places, compact where the text was small). Per-source rows pass the source's name, and catalogue rows retry.
- The test pack is plain files served from GitHub raw: Stremio's addon protocol is just JSON paths. Series were left out because their ids contain `:`, which Windows checkouts can't hold.
- **Source health** is kept by group name:
  - `tried` is stamped when a link is handed to the player, `failed` when a link falls back.
  - "Failing" means it failed at or after the last try, within three days.
  - The remembered source still goes first unless it is failing.
- No piracy repositories or addons were added: the pack uses legal sources plus the ecosystems Raygun already suggests.

## Verification
- **Tests:**
  - `SourceIssue` (calm title, details hidden until More info, Copy details);
  - the Developer card (report, failures as issues);
  - source health (failing set, forgotten after three days; a failing source goes last even if remembered);
  - all app tests (411), clippy, `cargo test --workspace`.
- **Windows (release build):**
  - "Add test sources" reported 8 added and 5 already there; "Install everything (5)" installed the five test extensions.
  - The log showed the throwing source failing, the garbage source reduced to its 2 valid songs, and the crashing one reported as failing to load.
  - Music search "By source" showed "Issue with MusicBrainz" and "Issue with NuclearTube" cards. More info gave "This source failed: Ytdlp isn't available to Nuclear plugins in Raygun yet" with Copy details.
  - Search found the issue below: before the 12 s limit, music results waited about 30 s on silent sources; after it, they came within the limit.
  - The test addon's Sintel skipped its 404 and 403 links and played the Blender 1080p file. The source list showed both dead links as failed; the stale "didn't work lately" on the addon's own name was fixed to clear when a link plays.
  - "Every link broken" ended calmly: "No source could play this. Pick another in Sources.", with Try again.
- **Android (Pixel_4 emulator):**
  - "Add test sources" reported 10 added and 3 already there, and offered 83 extensions to install.
  - Browse → Sources listed the test addon, Cinemeta, Public Domain Movies, YouTube, Pluto TV and Radios.
  - Sintel (fallback test) played in the native player after its dead links.
