# M46.27 — Local Files

## Goal
- **One list of folders for everything on the device:**
  - Library → ⋯ → **Local files**, and a Local Files block in Browse → Sources (`/local-files`), list the folders.
  - Add folder (desktop: a folder dialog; Android: the system folder picker). Each folder can be scanned again or removed.
  - "Find music on this device" stays as a one-tap way to add the music folders.
- **A scan sorts what it finds by kind:**
  - **Songs** (mp3, flac, m4a, ogg, opus, wav…) join the music library as before. They can be favorited, added to playlists, downloaded songs' sorting applies…
  - **Comics** (CBZ, ZIP, CBR is skipped; a folder of images counts as one chapter) become `local.comics` titles in Library → Comics, one title per file or per folder of chapters.
  - **Books** (EPUB) become `local.epub` novels in Library → Books.
  - **Videos** (mp4, mkv, webm, mov, avi, m4v) become titles of a new source `local.video` in Library → Videos. A folder of episodes becomes a series, and a lone file a movie. Progress and Continue watching work as for any video.
- **Scans run in the background** with a progress line, again at start (changed files only) and on demand.
  - A file that disappears takes its item with it, unless it was imported (comics and books are unpacked into Raygun's storage, so they stay).
  - Each folder shows counts by kind.
- **Android:**
  - Folders come from the system picker (a persisted tree permission). The `raygun-audio` plugin lists a tree (`listTree`: document address, relative path, size, modified) and opens a file for reading (`openInput`: a detached descriptor), because Rust can't open `content://`.
  - Songs and videos are read by path (`/storage/emulated/0/…`, from the tree's document id), which READ_MEDIA_AUDIO and READ_MEDIA_VIDEO allow. Pictures, comics and books are read through the folder's grant. Reading pictures by path would need the photos permission, which Raygun doesn't ask for.
  - Songs play from their paths as the music library's always have; videos play by path through the stream proxy (`PlaybackService::register_source`), as on desktop. Comics and books are read through the descriptor and unpacked as imports are now.

## Decisions
- **One folder list, kinds by extension:** a folder can hold anything. Sorting by extension (and by magic bytes for ZIPs) means no per-kind setup.
- **Comics and books are imported, songs and videos are referenced:** the readers need the unpacked pages and chapters. Songs and videos stream from where they are, so they don't take double the space.
- **The music library's own roots stay** (device music, typed folders). The local-files folders are added to them for songs, so the music library is still the one place songs are scanned and searched.
- **Video titles:** a folder whose files carry `S01E02`/`1x02`/`Episode 3` patterns is a series (season and number from the name). Otherwise each file is a movie named after the file.

## Verification
- **Tests:**
  - `raygun-db`: folders and their files, a place added twice keeping its row;
  - sorting files by kind, episode numbers from names (`S02E05`, `1x03`, `Episode 12`), paths of shared-storage folders, walking a folder (hidden folders left out);
  - UI: adding a folder, its scan line ("12 songs · 3 comics · 1 book"), removing it; the Browse → Sources block.
- **Test folder** (made with ffmpeg): a tagged MP3, a CBZ, a folder of three pictures, an EPUB and two episodes `Test Show S01E01/02.mp4`.
- **Windows (release build):**
  - Browse → Sources ended with the Local Files block. Add a folder opened "Add a folder to Local Files", and the scan reported 1 song · 2 comics · 1 book · 2 videos.
  - Library → Videos had "Test Show" (2 episodes, series). Start played S1 E1 in the desktop player and went on to S1 E2 by itself.
  - Comics had "Sketchbook" (the folder of pictures) and "Test Comic"; Books had "Local Book"; Audio had the song "Local Tone" (0:20), its album and artist.
  - The title page named the source `local.video` and offered downloads; both fixed: it reads "Local files", with no download buttons.
- **Android (debug build):**
  - Add a folder opened the system picker (Download → RaygunLocalTest → Use this folder → Allow), then asked for music and for photos and videos.
  - The first scan found 1 song · 1 comic · 1 book · 2 videos. The folder of pictures failed ("Permission denied" reading by path), which led to reading pictures through the grant.
  - Test Show played in the video player from its file and offered the next episode.
- The test folders and what they imported were removed afterwards.
