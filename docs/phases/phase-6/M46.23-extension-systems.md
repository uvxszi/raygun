# M46.23 — What Raygun can run

**Asked by the user (2026-11-02):** "we also need to list out the types of extensions and plugins we support, like the 2 other players i also just listed out, support those systems as well".

## What the other players have (research, 2026-11-02)
- **QuietPlay** (closed source): no add-ons. Its recommendations call Deezer and Apple Music with the user's top artists.
- **Musike** (MIT): no add-ons. It is a YouTube Music client (search, its automix radio).
- So there is no plugin format of theirs to load. What they offer arrives through Raygun's own sources:
  - QuietPlay's mixes and moods: Deezer's and Apple's charts and recommendations, Made for You (M46.19–M46.20).
  - Musike's YouTube Music: the first-party YouTube extension.

## Goal
- **Browse → ⋯ → What Raygun can run** (`/extensions/systems`) lists every system with what it brings and where to manage it:
  - Raygun extensions: the JS SDK's provider kinds, from repositories.
  - Nuclear plugins: converted at install.
  - Shosetsu sources: Lua.
  - Stremio addons.
  - Podcast and audiobook feeds.
  - Websites.
  - Imports: Mihon/Tachiyomi backups, CBZ/ZIP, EPUB, Spotify links, CSV, screenshots.
  - Other players: QuietPlay and Musike have nothing to load, and the page says what replaces them.
- **More of Nuclear's plugin kinds run:**
  - `dashboard` providers become `music.charts`: their top tracks as a "Top songs on <plugin>" chart.
  - `discovery` providers become `music.recommend`: `getRecommendations` as song radios.
  - `CONVERTER_VERSION` 3, so installed conversions are offered again.

## Decisions
- **Nuclear's dashboards:** only top tracks map onto Raygun's charts. Top artists, albums, editorial playlists and new releases (albums) have no chart shape yet, and are listed in the plugin's compatibility report as before.
- **Nuclear's discovery:** gets a one-song context: the artist, and the title when there is one.
- **Text:** the page is translated text, not data from the extensions, so it reads well even with nothing installed.

## Verification
- **Tests:**
  - nuclear-compat: a dashboard plugin converting to a chart of its top songs, and a discovery plugin to song radios;
  - the host still turning away plugins that only provide a queue or playlists, with the reason;
  - UI: the page listing every system with what it brings, and what other players became.
  - All app tests (432), nuclear-compat (16), clippy, `cargo test --workspace`.
- **Android (debug build):** Browse → ⋯ → What Raygun can run listed all eight systems, with Manage links for extensions, Nuclear, Shosetsu and Stremio.
- **Windows (release build):** the same page, from Browse's menu.
