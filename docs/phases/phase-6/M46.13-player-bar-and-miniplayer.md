# M46.13 — The phone's player bar, Connect, and the desktop miniplayer

**Asked by the user (2026-11-02):**
- "on mobile, make it so you can swipe on the mini player and it goes to next or previous song, remove the next song button, and at the left of + button, add a connect button to show syncing of devices like spotify";
- "make a pop out miniplayer on desktop that is a small window like this when hovered" (screenshots of Spotify's Miniplayer: the artwork, the title and artist with a saved check; on hover the controls over the artwork and the time).

**Relevant docs:** M42.1 (player bar), M46.4 and M46.7 (desktop bar), M21/M22 (device sync, on hold but present), M20 (remote).

## Goal
- **Phone player bar:**
  - swiping left plays the next song, right the one before (never just restarting the song), up opens the full player;
  - no Next button;
  - a Connect button left of +.
- **Connect** (also on the desktop bar): this device ("Playing here"), the paired devices and when each last synced, Sync now per device, setting up or managing pairing, and controlling Raygun from another device (the remote).
- **Desktop miniplayer:** a button in the player bar opens a small window that stays on top:
  - the artwork, title and artist, and the saved mark;
  - on hover over the artwork: mute, shuffle, previous, play/pause, next, repeat, back to Raygun, the time and a seek bar;
  - the top edge drags it and has a close button.

## Design
- **Swipes:** `player/swipe.ts` (`swipeAction`, pure) reads motion's drag offset and velocity; the bar drags on both axes with direction lock and snaps back. The song before is found in the queue's play order (`PlayItem`), wrapping with repeat all.
- **Connect:** `devices/ConnectButton.tsx` over `useSyncStatus`/`useSyncNow`; it links to `/settings/devices` and `/settings/connections`. Raygun has no casting, so Connect shows the devices sync keeps in step rather than outputs.
- **Miniplayer:**
  - `raygun-app/src/miniplayer.rs` (`miniplayer_open`/`miniplayer_close`) builds a Tauri window `miniplayer`: 320×384, no frame, always on top, resizable, sharing the main window's webview profile.
  - It loads the same `index.html`; `main.tsx` sees the window's label (`miniplayer`) and renders `miniplayer/MiniplayerApp.tsx` instead of the router, so the window has no shell and, above all, no second set of playback engines. It follows playback through the same events (`usePlaybackSync`) and sends `playbackControl`.
  - The capability covers both windows (dragging, closing).

## Done-check
- Vitest: swipe rules; the phone bar without Next, with Connect listing devices and syncing one; the desktop bar's miniplayer button; the miniplayer's controls, back and close.
- 🖥️ Windows: open the miniplayer, hover, play/pause and skip from it, drag it, go back to Raygun.
- 📱 Android: swipe the bar both ways; open Connect.

## Decisions
- **Swiping back plays the song before**, not Previous: Previous restarts a song more than 3 s in, and a swipe should always change the song. At the start of the queue, a swipe right restarts the song.
- **Connect shows synced devices.** Raygun can't send playback to another device (no casting, and sync is about library and settings). So Connect is honest about what's there: this device, paired devices with their last sync and Sync now, and the ways to pair or to use the remote. Sync stays off by default (the user put it on hold); Connect explains it and links to its setup.
- **The miniplayer is a second window on the same page.**
  - It is told apart by its Tauri label, because an app URL is a path only: the first try with `?window=miniplayer` never reached the page.
  - It shares the main window's webview profile (one browser process, the same storage).
  - It never starts engines: playback stays in the main window and the miniplayer only sends controls and follows events, so closing it changes nothing about what plays.
- **Its commands are async:** on Windows, a window built inside a synchronous command stayed on `about:blank` (found with WebView2's local debugging port).
- **Size and look:** 320×384 by default, resizable down to 200×240, always on top, no frame. The controls show on hover (or keyboard focus) over the artwork, as in Spotify's. Space toggles play, Ctrl+←/→ skip.
