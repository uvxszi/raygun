# M46.38 — Comics and books: chapter order, the website button, the novel reader, other sources; JPEG XL and other apps' repositories

## Goal
- **Chapter order on title pages** (comics and books): a sort and filter button beside the chapter count (`manga/ChapterOrderButton.tsx`, `manga/chapterOrder.ts`).
  - Sort by **Source order**, **Chapter number** or **Upload date**; picking the sort again turns it round. Chapters without a number or date go last.
  - Show only **Unread**, **Started** or **Downloaded** chapters.
  - Kept per title on the device.
  - The library's sorts already had Total chapters, Latest chapter (last updated) and Unread (M46).
- **The website button** opens the title's page in Raygun's browser (`catalog_open_page`). A plain link did nothing in the app's window, which was the bug. A source address that's only a path is joined to the source's website. Without one, the website itself opens. Local titles have no button.
- **A narrower novel reader:** the scrolled column was already narrow. Paged mode laid its columns across the whole window; its pages now keep to the column's width (Narrow 46 rem, Wide 64 rem), centred.
- **Find in other sources** on comic and book pages (`manga/OtherSources.tsx`): every other enabled source is searched for the title. Close matches (search's own title score) are listed with their source, each with **Open** and **Add** (which stores the title, then adds it).
- **Favorited but not in the library:** favoriting already adds a title to the library (`library_actions::set_mark`). Checked on the emulator with a book from the Gutenberg source.
- **JPEG XL:**
  - Pictures sources serve as JPEG XL are decoded (jxl-oxide, pure Rust) and kept and served as PNG, since no webview shows JPEG XL (`raygun_net::images::jxl_to_png`).
  - **Save cover image** offers **JPEG XL** beside JPEG, PNG and WebP: a lossless encode by zune-jpegxl. Android files it under Download/Raygun, since MediaStore's pictures refuse types Android doesn't know.
- **Other apps' repositories:**
  - Adding a Mihon/Aniyomi, CloudStream, LNReader or Miru repository, or a Stremio addon, as a repository now says what it is and why Raygun can't add it (`RepoError::Foreign`), instead of a JSON error.
  - The local Paraline Community repo lists each format's public index (`REPOS.md`, `repos.json`) for testing.

## Decisions
- **AI in the reader waits for its engines:**
  - The upscaler models download (M34), but nothing runs them yet: that's ncnn/Vulkan work planned with the rest of "AI for manga".
  - The text reader (OCR) reads Latin script only and gives line starts, not boxes, so translations can't be drawn over speech bubbles yet.
  - Switches that do nothing would mislead, so the reader's AI panel comes with those engines, as its own milestone.
- **Caches aren't converted to JPEG XL:**
  - No webview shows it: every cached cover would be decoded again each time it shows, which makes covers slower.
  - The pure-Rust encoder is lossless only, which makes already-compressed JPEG and WebP covers bigger, not smaller.
  - Real savings need libjxl (its lossless JPEG recompression), a C++ build for every target. JPEG XL is offered where it helps: reading it from sources, and saving it.
- **Chapter order is a display choice,** kept on the device like the library's display options.

## Verification
- Android: the book page showed the chapter sort button (Source order, Chapter number, Upload date; Unread, Started, Downloaded), Find in other sources (Read From Net and Wattpad matches with Open and Add), and the **WebView** button opened Project Gutenberg's page for the book in Raygun's browser.
- Favorite: favoriting a book not in the library put it in Library → All → Books. Taking it out of the library left Favorite on; taking a title out of the library now clears its favorite, list and pin.
- Found and fixed:
  - Gutenberg's audio recordings showed as books and their pages failed (HTTP 404). The search now leaves them out (Gutenberg 1.0.1).
  - A failed or loading title page now shows the title and cover the list already had (`manga/knownCard.ts`).
  - The video title page's website button used a new window, which does nothing in the app; it goes through `catalog_open_page` too.
  - "Source order · Newest first" read wrong for sources listing in book order; it says "As the source lists them" / "Reversed".
- Tests: `chapterOrder.test.ts`, `title_pages_resolve_against_the_website`, `other_apps_repositories_are_named`, the JPEG XL round trip in `export::covers`.
