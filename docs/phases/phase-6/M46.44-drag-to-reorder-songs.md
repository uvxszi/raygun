# M46.44 — Drag songs into your own order

## Goal
- **A drag handle on every song** of a playlist and of Favorites (`TrackTable` with `onReorder`): a grip at the start of the row, shown on hover (always shown, dimmed, on touch screens). Dragging it moves the song; the keyboard works too (Space to pick up, arrows, Space to drop).
- **Any sort:** the order saved is the order you see.
  - In **Custom order** (ascending), dropping a song moves only that song (`playlist_move_item`, `favorite_move`), so sync sends one row.
  - Sorted by anything else (title, artist, added…), or reversed, the shown order with the move becomes the saved order (`playlist_set_order`, `favorites_set_order`) and the table switches to Custom order, so nothing jumps.
  - With a filter or a tag chip on, the song lands next to the one it was dropped on; hidden songs keep their places.
- **Favorites get a custom order:** `music_favorite.position` (synced, migration 0029). Until a song is moved its place follows when it was added (newest first, as before), so new favorites still arrive on top. Home's Latest favorites stays by date.
- The drop shows at once (the lists' cache is updated first), and the sort switch is written to the settings cache before it's saved.

## Decisions
- **Positions are midpoints, like playlists (M18):** a move writes one row unless the neighbours are too close, then the list is renumbered. Older devices that sync a favorite without a position leave it NULL, which reads as its added time.
- **Playlist edit mode keeps its up/down buttons** for people who don't drag; the handle shows in both modes.

## Verification
- Android: in Favorites, dragging Hello's grip to the top moved it; sorted by Title, dragging Hello to the top kept the shown order (Hello, Bohemian Rhapsody, Get Lucky) and switched the table to Custom order; after a restart the order was the same. Select all selected the three songs.
- Windows: the grip shows on hover in a playlist's table.
- Tests: `favorites_keep_the_order_they_are_dragged_into`, `a_playlist_takes_a_whole_new_order` (Rust), `dragOrder.test.ts`, TrackTable tests.
