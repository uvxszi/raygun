# M46.29 — Library blocks and a sidebar you arrange

**Asked by the user (2026-11-02), in one batch with M46.30–M46.32:**
- "downloaded block should be blue and always shows even if nothing there, local files block should be green block and also always show"
- "the left side quick buttons like the favorites and such should be customizable so you can right click anything and add it there or remove it also from the panel itself and you can drag it by order and have a button to set it to custom order or by last played from or selected"
- "do not put the local files folder under all of those sources, have a different button or something, or just from the block itself in library, make sure everything is intuitive and good for user experience"

## Goal
- **Three fixed blocks** lead Library → Audio → All's first row and Home's "Your music", always shown even when empty:
  - Favorites (red, as now);
  - Downloaded (blue);
  - Local files (green), with its folders' counts.
  - Local files opens `/local-files`: the folders, Add a folder, and what each holds, with links to where it went (Songs, Comics, Books, Videos).
- **Local Files leaves Browse → Sources.** Browse is for finding things online; what's on the device starts from the Library. The layout item `localFiles` is dropped from `browseSections`.
- **The sidebar is yours** (desktop rail, "Your library"):
  - It lists pins. Anything with a page can be pinned: Favorites, Downloaded, Local files, playlists, albums, artists, podcasts, audiobooks, comics, books, videos and mixes.
  - **Pin:** a right-click menu item, "Pin to sidebar", on cards and pages: playlists, albums, artists, podcasts, books, comics, novels, videos, mixes.
  - **Unpin:** "Unpin from sidebar" in the same menus, and in each pin's own right-click menu.
  - **Order:** drag pins to arrange them (custom order), or pick an order from the sidebar's sort button:
    - Custom;
    - Recently played (the last time something was played from it);
    - Recently opened (the last time its page was opened).
  - New playlists are pinned when made, as before. The first run pins Favorites, Downloaded, Local files and every playlist, so nothing disappears.
- Kept in `Settings::rail` (`RailPrefs`: `pins`, `order`, `seeded`). A pin is `{kind, to, search, name, artworkUrl, pinnedAt, playedAt, openedAt}`: the page's route and search, so anything with a page can be pinned. At most 300 pins.

## Decisions
- **Pins carry their name and artwork** as last seen, so the sidebar draws without loading every collection.
- **Stamps** (desktop, `useRailStamps` in `shell/useRail.ts`):
  - "Recently opened" is stamped whenever a pinned page is on screen.
  - "Recently played" is stamped on the page on screen when a new queue starts (its first item changes), which is when Play, Shuffle or a song starts from a page.
- **Colours:** Downloaded is sky blue (`sky-500`) and Local files emerald green (`emerald-500`). Both read on light and dark backgrounds, unlike the theme's accent, which the user may set to either.
- **Phones** don't seed or stamp: the rail is a desktop and wide-window feature (`shown` on `RailPins`).
- Code: `shell/useRail.ts`, `shell/RailPins.tsx`, `shell/PinButton.tsx`, `shell/usePinMenuItem.ts`, `library/LocalFilesTile.tsx`.
