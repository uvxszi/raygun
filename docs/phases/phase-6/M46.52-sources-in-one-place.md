# M46.52 — Sources in one place, one Add

## Goal
- **Sources** (`/sources`): extension repositories (every format Raygun reads), Stremio addons, connected servers and the extensions on the device, in one list.
  - Kind pills: All, Repositories, Addons, Servers, Extensions. Media pills: Audio (music, lyrics, podcasts, audiobooks), Videos, Comics, Books, Other.
  - Rows keep what they had: details and what they hold, the on/off switch (addons, servers, extensions), bulk selection, addon order, removal, 18+ marks, suggestions.
  - `/watch/addons`, `/extensions/repos` and `/extensions?tab=repos` lead to it. More and Settings → Browse have one Sources entry; Browse's ⋮ menu opens it. Servers leave Browse → Sources, which gains an Audio section instead (one row per extension with audio sources, servers included).
- **One Add**: one address field. Look up asks Rust what the address is and shows it ("Looks like a Stremio addon: Cinemeta"), then Add adds it; a server shows its sign-in in the same sheet. When nothing matches, the sheet says so and offers connecting a server by hand.
- **Picking instead of typing**: a button beside fields that take a link or a path picks a file or a folder (`shell/LinkOrFileField.tsx`). A pick fills the field; in Add it's looked up at once.

## Detection (`raygun-app/src/source_detect.rs`)
- One fetch of the address (redirects followed, at most 10 MiB read), then the answer's contents decide:
  - JSON: a Stremio manifest; a server's answer; else a repository index (`repo::read_index`: Raygun, Nuclear's registry, Shosetsu, Miru, LNReader, Mihon). Other apps' repositories Raygun can't use say why (CloudStream).
  - XML: Kodi's `addons.xml` (a long one through `.gz`), a Kodi repository add-on naming its index, an OPDS feed.
  - A zip: a Raygun package, or a Kodi repository add-on. A script: Miru's metadata block or Shosetsu's metadata line.
- Nothing there: the places beside it are asked at once and the first in order wins: the addon manifest a bare address stands for, `index.json`/`index.min.json` in a folder, `addons.xml.gz`, and servers' endpoints (Jellyfin and Emby `System/Info/Public`, Subsonic `rest/ping.view`, Audiobookshelf `status`, `opds/v1.2/catalog`, `opds`) under the address and its site's root.
- An address without a scheme is tried as `https://`, then `http://` when that doesn't connect. Repositories and packages keep `check_index_url`'s rules (https, local test hosts, files Raygun may read).
- GitHub project pages stand for raw files: `repo` branch `index.min.json` (Mihon, Aniyomi), then `HEAD/index.json`, `HEAD/index.min.json`, `HEAD/manifest.json`, `HEAD/plugins.json` (Nuclear), LNReader's `plugins/v3.0.0/.dist/plugins.min.json`, `HEAD/addons.xml`; `/tree/<branch>/<folder>` and `/blob/…` pages for their folder or file. GitLab pages use the Shosetsu candidates.
- A folder on the device stands for the index in it.
- What was found is kept for ten minutes, so Add doesn't fetch again.

## Decisions
- **Mihon and Aniyomi**: their indexes are read as repositories of format `mihon` (`raygun-ext-host::mihon`, ids `mihon.<lang>.<name>`, Aniyomi's `mihon.anime.…`). Installs go to the `mihon` runtime; this build has none, so the catalogue marks the entries and installing answers "Mihon extensions aren't supported on this device yet".
- **One extension on its own** is installed from the file read when it was found, checked as a repository entry built from its own manifest or metadata (`package::entry_of`, `miru::package::entry_of`, `shosetsu::package::entry_of`); a Shosetsu script takes its libraries from the Shosetsu repositories added. No repository offers it updates.
- **Repositories have no switch**: none had one; turning a repository's extensions off is done on them.
- **Android picks are copies**: the system picker's item is read through the plugin and copied into `picked/` in the data folder, since what fields lead to reads paths; a picked folder's copy is a snapshot (pick it again for changes). Repositories are read from files only there on Android.
- **Repository names**: an index without a name of its own on a project called `extensions`, `repo`, `index`… is named after its owner (`keiyoushi`).
