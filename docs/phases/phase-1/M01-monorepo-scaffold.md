# M01 — Monorepo scaffold

**Relevant docs:** ARCHITECTURE §4 (repo layout), §11 (UI stack), §12 (typed boundary). reference-notes → nuclear (monorepo/tooling).

## Goal
An empty but correctly-shaped Raygun monorepo. It builds and runs on the Android emulator and on Windows, and proves the typed Rust ↔ TS boundary end to end.

## Scope
- Root: `package.json` (pnpm workspace + turbo), `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json`, ESLint (flat config) + Prettier, root `Cargo.toml` workspace, `rustfmt.toml`, `.editorconfig`, `.gitignore`.
- `apps/raygun/`: Vite + React 19 + TS strict + Tailwind v4; `src-tauri/` as a **thin shell** that calls into `raygun-app`.
- `crates/raygun-model`: first shared type (`AppInfo`) deriving `serde` + `specta::Type`.
- `crates/raygun-app`: service wiring + command layer; the `app_info` command returns `AppInfo` (name, version, platform, arch, debug flag).
- `packages/bindings`: TS generated by tauri-specta at debug startup / via `cargo test` export; never hand-edited.
- Android project generated (`tauri android init`), identifier `app.raygun.player`.
- Tests: one Vitest + RTL test of the home screen with mocked bindings; one Rust test for `app_info` that also exports the bindings and fails if they're stale.

## Out of scope
Portable paths (M02), DB (M03), real navigation/shell (M04).

## Done-check
- `pnpm install && pnpm lint && pnpm test && cargo test --workspace` pass.
- `pnpm android:dev` runs the app on the `Pixel_4` emulator and the home screen shows the data returned by `app_info` (platform = android).
- `pnpm dev` opens the desktop window showing the same data (platform = windows).
