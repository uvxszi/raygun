Raygun 1.3.1 fixes Made for You filling the disk with log messages.

## Fixes

- Made for You no longer retries without pause when sources don't answer. Before this fix, a source that failed every time (such as a media server that isn't connected) could make Raygun write gigabytes of log messages a day. It now waits 30 minutes before trying again; refreshing Made for You still tries at once.
